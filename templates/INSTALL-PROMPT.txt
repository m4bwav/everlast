Install the Everlast Protocol on this machine so nothing AI sessions learn is lost across tools. Do all of it, verify each step by its output, and report in five lines.

1. Clone the plugin: `git clone https://github.com/m4bwav/everlast-protocol` under the local plugin root (an existing marketplace folder such as ~/claude-plugins or D:\m4bwa\Claude\Projects\Ai if present; otherwise ~/claude-plugins). If it is already cloned, `git pull` instead. Private repository: run `gh auth login` first if git asks.
2. Clone the vault: `git clone https://github.com/m4bwav/everlast-vault` to the path in the plugin's everlast.config.json for this OS (Windows: D:\m4bwa\Documents\Everlast\vault; otherwise ~/everlast-vault). If that drive does not exist, clone to ~/everlast-vault and set EVERLAST_VAULT to it. Already cloned: `git pull`.
3. Claude Code: `claude plugin marketplace add <plugin clone dir>` (if a marketplace already lists it, `claude plugin marketplace update <name>`), then `claude plugin install everlast-protocol@everlast --scope user` (or `@<marketplace name>`), then `claude plugin list` to confirm.
4. Other agents on this machine (Copilot, Codex, OpenCode, Windsurf): `python <plugin>/scripts/everlast.py export ~` so the skills appear under ~/.agents/skills. Cursor or Gemini CLI: also link them into ~/.cursor/skills or ~/.gemini/skills. Cowork: `python <plugin>/scripts/everlast.py pack` and upload the .plugin file through Customize > Plugins.
5. Verify: `python <plugin>/scripts/everlast.py vault status` and `project list`. Then read <vault>/user/PROFILE.md and the ENVIRONMENTS.md section for this machine (add a section if this machine is new, and log it with `everlast.py log . --user --op update --title "new machine <name>"`).

Report: plugin path and version, vault path and remote, projects registered, which tools got the skills, whether ENVIRONMENTS.md was updated.
